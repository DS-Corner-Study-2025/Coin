# 17장 타임스크립트 노드 개발

- 최근 노드나 웹에서 javascript 대신 타입스크립트로 개발하는 것이 트렌드가 되고 있음.
- 타임스크립트: javascript에 명시적으로 타입이 추가된 언어
- javascript에도 문자열, 숫자 등의 타입이 있음. 명시적으로 타입을 지정하고 코드를 작성하지 않을 뿐임.
- ts 코드는 tsc 라는 컴파일러를 통해 js 코드로 변환할 수 있음. 노드는 js만 실행할 수 있으므로 반드시 ts를 js 코드로 변환해야 실행 가능함.
- 디노(deno): ts를 실행할 수 있는 런타임

## 타임스크립트 기본 문법

- 콘솔로 typescript 패키지 설치하면 컴파일러도 같이 설치됨. tsc 명령어로 컴파일러 작동 가능
- tsc 명령어는 tsconfig.json에 적힌 설정대로 실행됨.

## js vs ts 비교

```
// compare.js
let a = 'hello';
a = 'world';
```
```
// index.ts
let a = 'hello';
a = 'world';
```
- 이 경우에는 둘 모두 에러가 일어나지 않음.
ts 파일은 npx tsc를 통해 js로 변환 후 index.js가 생성되면 성공임.
```
// compare.js
let a = 'hello';
a = 123;
```
```
// index.ts
let a = 'hello';
a = 123;
```
- 그러나 이 경우 ts파일에서 TS2322 에러가 발생함. 변수 a가 string 타입을 갖는데 타입이 numer인 123 값을 넣었다는 것임. ts는 변수라 하더라도 고정된 타입을 가짐.
- 개발할 때 변수에 처음과 다른 타입의 값을 넣는 일은 흔치 않으므로 실수를 방지할 수 있음.
- 에러가 발생해도 index.js는 그대로 생성됨. (js 변환됨)
- 타이핑: 타입을 붙이는 행위. 변수와 함수의 매개변수, 반환값에 타입을 붙인다고 생각하면 됨.

```
// js
function add(x,y) {return x+y};

// ts
function add(x: number,y: number) number {return x+y};
```
- 이런 식으로 콜론 뒷부분이 타입 자리임. ts는 코드로부터 타입을 어느 정도 추론할 수 있으므로 에러가 발생하지 않으면 적지 않아도 됨.



## 커뮤니티 타입 정의 적용하기

- allowJs 옵션: true로 적용하면 일부만 ts로 변환해도 다른 js 코드와 함께 사용할 수 있음.
- 기존에 만든 js 파일의 확장자를 ts로 변경하고 모듈 시스템을 CommonJS 에서 ECMAScript로 변경해야 함.
- DefinitelyTyped 패키지: 익스프레스처럼 ts로 작성되지 않은 js 패키지가 많음. DT 패키지는 이러한 라이브러리에 타입 정의를 적용해두었음. npmjs.com에서 패키지들의 ts 작성 유무를 알아볼 수 있음.
- 패키지 이름 앞에 @types/가 붙은 패키지들은 DT 커뮤니티에서 제공하는 타입 정의 패키지

## 라이브러리 코드 타이핑하기

- ts는 시퀄라이즈의 속성을 자동으로 파악할 수 없으므로 직접 속성을 타이핑해줘야 함.
- ts는 폴더 내 파일의 타입을 추론할 수 없기 때문에 하나씩 수동으로 import하는 방식으로 돌아감.
